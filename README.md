# competition-doc-standards

创新创业大赛文档制作规范 Skill for Claude Cowork

作者工作记录称，规范参考了第八至第十二届互联网+创新创业大赛中的110个 DOCX、50个 XLSX、71个 PDF 和6个 PPTX 文件。由于样本清单、原始文件（或可公开的脱敏摘要）和分析记录目前未随仓库发布，这些数量属于作者报告的工作记录，外部读者暂时无法独立复核；本仓库交付的是规范手册，而不是原始语料或完整的逆向分析数据集。

## 适用场景

制作互联网+（中国国际大学生创新大赛）相关的 Word文档、Excel表格、PDF文件、PPT演示文稿时自动加载此规范。

## 内容覆盖

- **Word文档**：页面设置、字体字号（公文/学术两种风格）、表格规范、图文排版
- **Excel表格**：三种标准模板（信息登记表/汇总表/评分表）、列宽行高、合并策略、数据验证
- **PDF文件**：页面尺寸、字体嵌入、排版技巧、导出设置
- **PPT演示**：版式结构、配色方案、布局技巧、动画规范
- **通用规范**：文件命名、文件夹组织、排版检查清单

## 证据与可复现性

- 本仓库目前发布的是规范文本；未发布用于统计上述文件数量的样本清单、分析脚本或完整抽取结果。
- 阅读规范时，应把它视为基于作者经验与参考样本整理的实务建议，而不是由公开数据集自动推导的普遍定律。
- 若后续补充证据，建议先发布不含敏感内容的样本清单、文件格式/来源类别、文件哈希、使用的分析工具版本及统计口径；只有在许可允许时才发布原始文件。
- 字体、页边距、表格样式等建议应结合具体赛事、主办方最新模板与目标软件版本复核。

## 安装

将 SKILL.md 文件放入 Claude Cowork 的 skills 目录即可。
