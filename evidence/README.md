# 样本与分析证据：发布清单

## 当前状态

本仓库目前只公开规范手册。README 与 SKILL 中记载的“110 个 DOCX、50 个 XLSX、71 个 PDF、6 个 PPTX”是作者报告的参考样本数量；对应样本目录、清单、统计脚本和分析日志尚未随本仓库发布，因此此处不将其表述为已由公开材料复现的统计结果。

不应在没有许可的情况下公开参赛材料、包含个人信息的表格、评审材料或其他受版权/保密义务约束的文件。

## 建议的可复核交付

未来如补充证据，建议逐步加入以下不含敏感正文的元数据：

| 字段 | 用途 |
|---|---|
| sample_id | 仓库内不含个人信息的稳定编号 |
| format | DOCX / XLSX / PDF / PPTX |
| source_period | 来源年份或届次；未知时明确标注 |
| source_type | 通知、公文、计划书、评分表等类别 |
| public_or_permission_basis | 公开链接、授权依据或“仅内部使用” |
| sha256 | 如有合法留存的原始文件，对字节内容生成哈希以识别样本 |
| tool_and_version | 抽取工具名称与版本 |
| extraction_method | 自动提取、人工复核或两者结合 |
| observations | 该样本支持的具体规范观察，不粘贴受限内容 |
| reviewer_and_date | 复核者（可用团队代号）及复核日期 |

## 建议的验证流程

1. 定义纳入/排除标准，防止同一文件的重复版本被重复计数。
2. 对每种格式分别记录获取方式、文件数量、损坏或无法解析数量。
3. 为每一条规范记录适用场景、反例、软件/赛事版本和人工复核状态。
4. 对比例、均值或频次等定量主张发布计算口径和可执行的统计脚本。
5. 在不具备合规公开条件时，只发布脱敏后的汇总统计与方法说明，不发布原始文件。

在证据达到上述要求之前，正文中的排版建议仍可作为经验指南阅读，但样本数量和“来自实证分析”的描述应按作者工作记录理解。
